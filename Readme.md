## 💻 How to Run the Code

1. Clone this repository:

   ```bash
   git clone https://github.com/ayush-gangwar-09/Java-Data-Strucutres-Algorithms-with-Leetcode-Problems.git
   ```

2. Open the project in your preferred Java IDE.

3. Navigate to the topic or problem you want to practice.

4. Compile and run the Java file:

   ```bash
   javac Main.java
   java Main
   ```
